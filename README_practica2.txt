En este ejrcicio se nos plantea un problema en el que hay un fármaco nuevo para frenar la proteina BRAF mutada, pero solo funciona en pacientes que tienen un tipo concreto de mutacion.
Para poder resolver este problema, tenemos los datos de secuenciación de este gen de 40 pacientes con distintos tipos de cancer repartidos en 4 hospitales diferentes. Esta información está dentro de archivos guardados en .fasta, cosa que nos indica que estos docuentos tienen información sobre material genético.
Para poder resolver este problema lo que necesitamos es hacer un script que sea capaz de recorrer estos archivos de manera automática, buscar la secuencia CTACAGAGAAATC y que guarde los resultados en un único archivo. Este scrip tendrá que encontrar tanto la línea en la que se encuentra la secuencia indicada como la línea anterior a esta, para poder saber que paciente posee esta mutación. 
Para el desarroyo de este scrip he hecho un bucle for para que recorrer los 4 archivos diferetes. 
Antes de empezar el bucle, lo que hacemos es guardar la secuencia que tiene la mutación en una variable llamada "secuencia", para evitar errores posteriormente durante el bucle. Ademas añadimos !#/bin/bash para asi indicar a la terminal que el lenguaje que estamos utilizando en este script es bash.
Para empezar el bucle ponemos el for ... in ... que es la primera línea de la estructura del este bucle. En estos huecos ponemos una variable, en este caso "file" y una lista de elementos. Para poner esta lista utilizamos el "comodín" de *.fasta para indicar que tiene que entrar en todos los archivos que terminen en .fasta, y asi asegurarnos que entre en todos los archivos que contengan secuencias de ADN.
Continuamos con el do, que esta dentro de la estructura de este bucle. A continuacion de do, ponemos los comandos correspondientes. Para esta tarea utilizaremos un grep. Para que este comando sea preciso, neceistamos poner "-i" para que este obvie las mayúsculas y minúsculas y se centre en encontrar a todos los pacientes que tengan la mutación, ya que hay veces que los archivos que nos dan los hospitales no son del todo correctos y tenemos que asegurarnos de dar con todos los pacientes que tengan la mutación. Para finalizar con el grep, añadiremos a contuniación un " -B 1 " para que nos de también la línea superior de la secuncia y así podamos saber de que paciente se trata. Este comando necesita que le demos que tiene que buscar y donde, asique a continuación de este ponemos "$secuencia" haciendo referencia a la variable que anteriormente guardamos, en la que se encentra la secuencia que tiene que buscar y le ponemos "$file" para que asi sepa donde tiene que buscar. Finalmente redirecionamos los resultados a un archivo, que nombramos con una variable, y le pondremos nombre al archivo a través de la terminal cuando ejecutemos este script. Acabamos con la estructura del script con un done, y así le indicamos al ordenador que el bucle a terminado.
Una vez hemos acabado el script tenemos que asegurarnos de que funciona, por lo que en la terminal, dentro del directorio donde se encuentran los archivos que necesitamos, utilizamos el comando bash y a continuación ponemos este script y el nombre del archivo que va a crear. Una vez hecho esto la terminal no debería darnos una respuesta. Con el comando cat podemos observar si efectivamente este archivo se ha creado y si el contenido es correcto. Para poder contar el número exacto de pacientes, utilizamos el comando " grep -c "^>" ". En este comando indicamos que queremos que grep cuente cuantas veces está puesto el símbolo > que es el que aparece en la cabecera de cada secuencia, lo que significa que nos cuenta el número exacto de pacientes que poseen la mutación.    
Con todo esto habríamos puesto solución a nuestro problema y solo quedaría enviar los resultado correspondientes a cada hospital.
